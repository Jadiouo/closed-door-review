# closed-door-review
A Claude skill that simulates a panel of reviewers who score, debate, and produce line-by-line edits for your documents

## 流程圖（Workflow）

```text
┌─ 輸入 ──────────────────
│ 文件（一份或多份）
│ 已定案的決定
│ 已確認的事實
│ 硬限制（字數、頁數、格式、截止日）
└─────────────────────────
            │
            ▼
┌─ 過程 ──────────────────
│ 1. 選十位背景不同的委員
│ 2. 逐份審查
│ 3. 每位委員打分
│ 4. 自由辯論（至少五次衝突）
│ 5. 整理共識與未解決的爭議
│ 6. 寫作業單並機械檢查
└─────────────────────────
            │
            ▼
┌─ 輸出 ──────────────────
│ 逐份回饋、評分表、討論紀錄
│ 優先五件事、待你決定的事
│ 逐句修改作業單
│ 字數表、封版檢查表、停止條件
└─────────────────────────
```
